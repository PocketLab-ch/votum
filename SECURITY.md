# Sicherheitslücken melden

Haben Sie in Votum eine Sicherheitslücke gefunden, melden Sie sie bitte nicht als
Issue. Issues sind öffentlich: Die Lücke wäre für alle sichtbar, bevor sie behoben
ist.

Eine Sicherheitslücke ist zum Beispiel, wenn Sie Daten einer fremden Gemeinschaft
sehen, sich ohne Berechtigung anmelden oder etwas ändern können, das Ihnen nicht
zusteht. Sind Sie unsicher, nehmen Sie das Formular.

Schreiben Sie uns über das Kontaktformular:
<https://pocketlab.ch/kontakt/>

Das Formular nimmt Text bis 3000 Zeichen, aber keine Anhänge. Hilfreich sind:

- was Sie beobachtet haben, und an welcher Stelle (Adresse der Seite, Datum und
  Uhrzeit),
- wie es sich wiederholen lässt,
- welcher Stand betroffen ist, falls Sie ihn kennen (der Commit «Stand …» in
  diesem Repo).

Schicken Sie keine fremden Daten mit, die Sie dabei gesehen haben. Es genügt zu
beschreiben, was sichtbar war.

Wir antworten in der Regel innert weniger Tage. Bitte machen Sie die Lücke erst
öffentlich, wenn sie behoben ist. Bleibt eine Antwort aus, schreiben Sie noch
einmal über das Formular, statt ein Issue zu eröffnen.

Danke, dass Sie die Lücke melden.

Fehler und Fragen, die keine Sicherheitslücke sind, können Sie gern als Issue
melden. Pull Requests nimmt dieses Repo nicht an: Es ist ein Spiegel, entwickelt
wird an anderer Stelle.
